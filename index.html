只要連線至免費的 Supabase 資料庫，無論在手機、平板、公司電腦或家中設備開啟 https://sunnyportal.github.io/OS/，所有建立的分類與連結都會自動即時同步！
📋 第一次使用？在 Supabase 貼上此 SQL 建立資料表：
create table if not exists categories ( id text primary key, name text not null, icon text default '📁', color text default '#6366f1', sort_order int default 0, created_at timestamp with time zone default timezone('utc'::text, now()) ); create table if not exists bookmarks ( id text primary key, name text not null, url text not null, desc_text text default '', category_id text, badge text default '', badge_type text default 'hot', tags text[] default array[]::text[], icon_url text default '', is_pinned boolean default false, sort_order bigint default 0, created_at timestamp with time zone default timezone('utc'::text, now()) ); alter table categories enable row level security; alter table bookmarks enable row level security; create policy "Public Categories" on categories for all using (true) with check (true); create policy "Public Bookmarks" on bookmarks for all using (true) with check (true);
